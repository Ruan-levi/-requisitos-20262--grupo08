# Glossário do domínio — Portal de Internacionalização

**Grupo 08 · Versão 1.0, inicial · Base metodológica:** [Glossário LAPIS](https://github.com/marcelobezerra-dotcom/Lapis-unifor/blob/main/Requisitos/Artefatos/Templates/template-glossario.md).

| Termo | Uso no projeto | Observação |
|---|---|---|
| Internacionalização acadêmica | Iniciativas de cooperação e experiências educacionais internacionais. | Conceito amplo, não regulamento. |
| Intercâmbio | Modalidade de experiência acadêmica em instituição de outro país. | Verificar programas e editais oficiais. |
| Dupla titulação | Modalidade de formação vinculada a acordos que podem permitir dois títulos. | Condições dependem de convênio específico. |
| Mobilidade acadêmica | Realização de estudos ou atividades acadêmicas em outra instituição. | Regras variam por programa. |
| Edital | Documento que define condições, prazos e critérios de uma seleção. | Conferir sempre a fonte vigente. |
| Aproveitamento de disciplinas | Análise do possível reconhecimento de estudos realizados. | Somente o setor competente decide. |
| DRI | Sigla mencionada no **Tema 4** para o setor de internacionalização. | Nome e responsabilidades atuais a confirmar. |
| NEI | Sigla mencionada na **apresentação do projeto de extensão**. | Equivalência com DRI **não confirmada**. |
| Stakeholder | Pessoa, grupo ou instituição afetada pela solução. | Consultar mapa de interessados. |
| Persona | Representação fictícia para apoiar a definição de cenários. | Não substitui entrevista real. |
| RF / RNF / RN | Requisito funcional / não funcional / regra de negócio. | Códigos do projeto. |
| US | História de usuário no backlog do produto. | Priorização MoSCoW. |
| SRS | Especificação de Requisitos de Software. | Documento preliminar na P1. |
| MVP | Conjunto inicial de capacidades essenciais. | Produto ainda não implementado. |
| AD / SIM | AD = achado documental; SIM = hipótese da simulação de persona. | **Fontes de natureza diferente.** |
| Baseline | Versão aprovada como referência para mudanças futuras. | A criar por marco quando validado. |

**Manutenção:** revisar termos conforme novas fontes, entrevistas verdadeiras e decisões institucionais.
